## Tujuan Praktikum

Praktikum ini bertujuan membangun pemahaman konsep jaringan komputer secara praktis melalui observasi langsung lalu lintas jaringan menggunakan Wireshark dan implementasi pemrograman socket dengan Python.

Topik yang dipelajari:

| Modul | Topik |
|-------|-------|
| 1 - 2 | Instalasi dan penggunaan dasar Wireshark |
| 3     | Analisis protokol HTTP |
| 4     | Analisis protokol DNS |
| 5     | Analisis UDP dan query DNS |
| 6     | Analisis protokol TCP |
| 7     | Pemrograman socket UDP dan TCP |
| 9     | Implementasi web server berbasis socket Python |
| 10    | Analisis ICMP dan traceroute |
| 11    | Analisis protokol DHCP |
| 12    | Pengujian konektivitas dengan ping dan traceroute |
| 13    | Analisis protokol ARP |
| 14    | Analisis frame IEEE 802.11 (Wi-Fi) |
